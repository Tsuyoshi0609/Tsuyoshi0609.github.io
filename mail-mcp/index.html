tsuyoshi-mail-mcp

tsuyoshi-mail-mcp は、開発者本人が自分のメールアカウントを Claude などの AI アシスタントから操作するために使う、個人用の MCP（Model Context Protocol）サーバーです。

一般向けのサービスではなく、開発者本人のアカウントでのみ使用します。

tsuyoshi-mail-mcp is a personal MCP (Model Context Protocol) server that lets the developer access their own mailbox from an AI assistant. It is not offered as a public service.
