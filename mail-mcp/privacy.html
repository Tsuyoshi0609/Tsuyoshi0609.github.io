プライバシーポリシー

最終更新日: 2026年9月28日

tsuyoshi-mail-mcp（以下「本アプリ」）は、開発者本人が個人的に使用するためのアプリケーションです。

1. 取得する情報

本アプリは、ユーザーが Google の OAuth 同意画面で許可した範囲で、Google アカウントのメールデータ（メッセージ、ラベル、下書きなど）にアクセスします。

2. 利用目的

取得した情報は、ユーザー本人の指示に基づくメールの閲覧・検索・整理・作成・送信のためだけに使用します。

3. 保存と第三者提供

認証トークンはユーザー自身のコンピューター上にのみ保存されます。本アプリの開発者がデータを収集・保存するサーバーはなく、取得した情報を第三者に販売・提供することはありません。

4. Google API サービスのユーザーデータポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API Services User Data Policy に準拠します。

5. アクセスの取り消し

ユーザーは Google アカウントの権限設定 からいつでも本アプリのアクセスを取り消すことができます。

Privacy Policy

tsuyoshi-mail-mcp is a personal application used only by its developer. It accesses Gmail data solely within the scopes the user grants, only to carry out the user's own instructions. OAuth tokens are stored only on the user's own computer; no data is collected on any developer-operated server, and no data is sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: tsuyoshi.soccer.69@gmail.com
